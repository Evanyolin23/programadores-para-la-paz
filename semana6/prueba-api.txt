Al enviar una petición POST a la ruta /registro con el siguiente JSON:

{
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

el servidor recibe los datos enviados en el cuerpo de la petición y responde con un objeto JSON que confirma la recepción de la información.

Respuesta obtenida:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}
